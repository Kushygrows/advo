How to get your notes out of each app first

Advo reads plain text and Markdown (.md/.txt) — it can't open each app's proprietary file directly, so export or copy first:

  • Obsidian — best fit, no export needed. Your vault is already a folder of .md files; use "Select a vault folder" below and point it at the vault.
  • Notion — open the page or workspace, ••• → Export → Markdown & CSV, unzip the download, then use "Select files" and pick the .md files.
  • Microsoft OneNote — no clean bulk-markdown export exists. Easiest path: open a page, select all, copy, and paste into the box below. For many pages at once, File → Export a section as Word, then copy the text out of Word.
  • Apple Notes — same limitation, no built-in bulk export. Select a note (or several), copy, and paste below. For one note at a time, you can also use File → Export as PDF and copy the text from the PDF.

🔒 Privacy & storage

Your fact bank autosaves to this browser's local storage in plain text by default — see the note at the bottom of this page. If this device is shared, or you're working with a sensitive subject, you can turn on passphrase encryption below. Advo never stores the passphrase anywhere (same rule as your API keys), so there is no password reset — forgetting it means that autosaved data is gone for good.

Nothing here is saved anywhere, and Advo has no account or server to recover it from. Write your passphrase down somewhere safe before continuing.

Honest limits: this app runs entirely offline in your browser — it has no live internet connection, so it cannot fetch new facts or news on its own for any subject. All research still has to come from an actual research pass (Claude, or your own reading) that can check current, official sources — this app only helps you organize, rotate, and format what's already been verified. Every fact here should carry its original source link — don't post anything that isn't sourced. Source-tier badges and the readability score are mechanical heuristics (domain suffix, sentence/syllable counting) — useful signals, not proof of accuracy. Outlet lean badges (📰) are attributed, sourced ratings from AllSides Media Bias Ratings, not Advo's own judgment — other rating projects sometimes disagree, ratings change over time, and a lean rating describes an outlet's general tendency, not whether any single fact from it is accurate. Advo autosaves your fact bank and subject to this browser's local storage so a refresh doesn't lose your work — nothing else (no API key, no license key, no drafts you haven't put in the fact bank) is ever written to disk on its own. That autosave is plain text by default; if you're working with sensitive material, see 🔒 Privacy & storage above for an optional passphrase-encrypted autosave.
